# R7 -- The rate controls sit together, always

**Done, and off the rules list, 2026-09-14.** Checked in every plugin that day, in REAPER's
own order (by slider number): every rate value is followed directly by its mode. That holds
for the main rates, the pan rates, Womb's heart and breath, Bubbler, Dapple, and the
Morpher's auto-morph time. The third member R7 named, `Host ratio`, was retired by R20. No
pan rate is called `Unit` any more; all say `mode`. All three filters' pan rate modes carry
the full five-entry list (R21).

**What a rate value's NAME carries, settled by Rozaya the same day.** The check turned up
rate values with no unit list in their names (Melody's `Rate value`, the pan rates). Claude
called that a leftover. Rozaya: *"That's not a bug. it's handled by rate mode, so that rate
value is just rate value for that mode."* And, on Polyrhythm's shared rate: *"Rate value
(all voices) would have been fine. the unit shit is for the unit mode."*

So a name says WHICH rate it is when that is unclear; the mode beside it says the unit.

**How the opposite got written down.** On 2026-09-07 Rozaya said of rebuilt Polyrhythm, *"the
rate at the top wasn't marked as anything"* (commit `3dcfd88`). That session read it as a
request for a unit list and put one back, adding "all voices" too. Polyrhythm's page then
retold it as a rate that "named neither its unit nor its scope", and R22 retold that as "the
fix Rozaya asked for". Both retellings were corrected 2026-09-14. The missing part was scope.

The rule as it stood, verbatim:

## R7. The rate controls sit together, always

`<rate slider>` → `Rate mode` → `Host ratio`, in that order, adjacent, no exceptions.
This is what makes `Rate Value` legible and it is what dissolves the `Sweep Rate` /
`Pan Sweep Rate` confusion.

Applies to the secondary rates too: `Pan sweep rate` → `Pan sweep rate mode`. Note the
current suite calls this one `Unit` where the primary is called `Mode`; standardise on
**`mode`**. Sweep Dwell's pan unit offers `Host x` and the other two filters' do not —
they should all offer it.
