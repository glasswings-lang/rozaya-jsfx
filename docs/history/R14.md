## Destination semantics were tried once and rejected, 2026-06-09

Moved out of the plan 2026-09-09.

Womb v3 originally had destination semantics and Rozaya rejected them — because
the amount defaulted to 0, so engaging the ramp meant "take the heart to 0 BPM"
and the sound died.

That was a **default problem misdiagnosed as a semantics problem**, and the
semantics were thrown out to fix the default. R14 brings them back with the
actual fix: the destination seeds to where the parameter already is, so "ramp to
where I am" is no change, safely, and any move from there states a goal. It is
the same continuity trick that makes entering Host x silent, which the suite has
now implemented twice and trusts.

**So the seeding is not a detail of R14. It is the thing that failed last time.**
