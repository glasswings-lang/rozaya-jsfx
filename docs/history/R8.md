# R8 — history

**Done, and off the rules list, 2026-09-14.** Every control that means the same thing now has
the same step, the finest one in use, wherever the plugin can honour it. Rozaya said yes.
Play for and Rest for stay whole numbers in plugins that count whole beats or steps
(Heartbeat, Rhythm Track, Melody, Shepard Scale, Womb's heartbeat and bloodflow), because
there a fraction would act as the next whole number. Womb's heart rate floor went from 1 to
0.001, as Heartbeat's already was. The rule's "structural" cure, sizing a slider to a
sensible change, was already turned down by Rozaya: *"I don't want to lose range. I don't
want to have to abstract away things because you've decided I can't count."*

## The two drafts this rule replaced, moved out of the plan 2026-09-09

**Draft one said the opposite of the rule** — that a slider should land in
roughly 100-1000 positions, and that a million positions meant the precision was
fictional.

**Draft two said you can only arrow in the parameter list, never type.**
CORRECTED 2026-08-31 by Star: focus a parameter, Tab, and there is an editable
value field; and in the FX dialog you can type into the box beside the slider.

## The rule as it stood, verbatim

**Rule: the step is set by the finest adjustment you would ever want to make. The range
is set by the widest value you would ever want to reach. How many positions that produces
is not a problem to be solved.** Where two plugins disagree on the step for the same
control, **take the finer one.**

What a step controls is not how far you have to travel — you can always type — it is **which values
exist at all**. A step of 0.1 where 0.05 is needed means 0.05 cannot be set by any means,
typed or arrowed, because the control quantises to the step. So a coarse step does not
make a value awkward to reach; it deletes it.

(Star, 2026-08-31: *"you don't need extra sliders or anything. You can just trust the
ears."*)
(Rozaya, 2026-08-28: *"I want the full range of stuff, and I want it to have the fine
grain control, not the hundredfold bullshit."*)
