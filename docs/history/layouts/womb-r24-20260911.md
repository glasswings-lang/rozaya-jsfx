## Breath rate in Beats — the one meaning that changes

Seconds: unchanged, a delta in breaths per minute. Beats: a delta in beats per
breath, so a positive amount is a LONGER breath. Only `womb-and-baby` uses it in
Beats (Random, up 5 / down 10 per minute, period 50, tempo 70, a 4.67-beat breath:
3.5 to 14 beats). Proposed conversion: up 9.333344 / down 1.166667 beats -- the same two
extremes, a different path between, and the fast and slow sides swap (Random, so
statistically the same). Cannot be bit-identical; said so.

## How the values are read

Rebuilt per block from `@slider`'s own formulas with drift and ramp folded in, so
with none each is exactly `@slider`'s: pitches, fine tunes, Tuning reference,
decays, Brightness, HB width, breath filters, bloodflow shape and filter. Per
sample: the volumes, fades, Sigh interval and extra, Play/Rest. The inhale/exhale
filters keep their per-sample path while any of 19-22 or 32 moves.

## Save format and memory

Magic `2500011 -> 2600049`; 2500011 and 2400011 read at eleven, 2300010-2100010 at
ten, each field only where it was held, then remapped with both selectors and
Drift movement. Banks respaced to 64-slot stride from 8192 (the last table ends 9968). The
drift loop runs the old eleven FIRST, in their old order, so `rand()` draws land as
before.
