## Save format and memory

Magic `2500007 -> 2600018`; 2500007, 2400007 and 2300005-2100005 are read at their
own width. Eighteen outgrew the 16-slot stride, so the per-target banks moved to
32-slot spacing from 8192 (addresses only; the blob is a sequence). `@init` draws
`rand()` for the older seven only.
